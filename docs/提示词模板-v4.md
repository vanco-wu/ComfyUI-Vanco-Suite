# 提示词模板 · Vanco 分镜编排引擎

> **模板版本 v4**（2026-11-20）：在 v2 高密度写法基础上，加入**镜头纪律**——
> 位置坐标块、动作动词黑白名单、说话人正反打、关键信息可视化。
> 这四条是 2026-11-18《头七》28 段实拍事故 + 2026-11-19《最后一班》10 段验证片得出的，
> 《最后一班》用 v3 规则后，肉眼可见的毛病基本消失。
> 目标密度：**每 8 秒 ≥1200 字，每 10 秒 ≈ 1500–2000 字**。

> 给写剧本的智能体用。读完你应该能直接产出**可以粘进「分镜编排引擎」的整篇分镜**。
> 结构：**怎么用** → **头行** → **素材与角色卡** → **正文六段** → **高密度写法** →
> **镜头纪律（v3 核心）** → **写作规则** → **自检清单** → **成品示例** → **失败修法**。

---

## 〇、怎么用（先读这段）

1. 你是一名分镜师 + 提示词工程师。用户给你剧情，你拆成若干**镜头块**，每块对应一次生成（4–10 秒）。
2. **输出纯文本**：只有镜头块，不要解释、不要前言、不要 markdown 标题。
3. 每块 = **一行头 + 六段式正文**，块之间空一行。
4. 动手前先问清四件事（没给就用占位名并在最后提示）：
   - **素材顺序**：第几张是场景、第几张是谁（序号必须准确）
   - **出片比例**：竖屏 / 横屏（决定角色卡比例）
   - **总时长**：决定拆几段
   - **每个角色的声音**：年龄性别、音高、语速、口音、说话习惯

## 一、头行格式（必须遵守）

```
[1] 续接=新图:1 角色=男主,女主 图=1,2,3 秒=8
[2] 续接=上一段 角色=男主,女主 图=2,3 秒=8
[3] 续接=新图:4 角色=女主 图=4,5 秒=6
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `图` | `图=2,3,5`（**必填**） | 本段只用这几张素材，顺序即参考顺序。不写=喂全部（上限 8 张，易串人） |
| `续接` | `新图:N` / `新图:名字` / `上一段` | 唯一决定起幅图。名字写错**不报错**，会静默用第 1 张 |
| `角色` | `男主,女主`（**逗号后不能有空格**） | 引擎按数量核对画面人数 |
| `秒` | 4–10 的整数 | 引擎换算帧数并对齐 17k+5 网格 |

### ⚠️ 三条硬规则

1. **一条链最多 3 段**（连续 `续接=上一段` 的段数）。实测第 4 段起：亮度掉一半、饱和涨 60%、皮肤出橙红斑块。
2. **断链处必须换机位或景别**，否则看起来像"卡了一下"而不是切镜头。
3. **断链 ≠ 换景（最容易误解的一条）**
   `续接=新图:N` 里的 N 只决定"这一段用哪张图当起幅"，**不代表必须换成另一张场景图**。
   - **同一场戏里断链**：图号**不变**，仍用同一张场景图（例如一直是 `新图:1`），只改机位/景别
   - **剧情真的换了地点**：才换到另一张场景图（例如 `新图:2`）
   - 反例：客厅戏每 3 段就切到 `新图:2` 的卧室 → 观众看到的是人物**瞬移**
   同理，`图=` 里的素材编号也可以始终不变，只靠机位描述区分镜头。
3. **接力是参考，不是硬接**：`续接=上一段` 会把上段尾帧当参考图，构图/景别/姿态仍可能重新生成。要锁构图用 `硬接模式`。

### 图号怎么编

```
新图:2 + 图=2,3,4  →  <Picture 1>=素材2（起幅） <Picture 2>=素材3 <Picture 3>=素材4
上一段 + 图=3,4    →  <Picture 1>=上一段尾帧  <Picture 2>=素材3 <Picture 3>=素材4
```

**`<Picture 1>` 永远是本段起幅图**，其余按 `图=` 顺序往后。写正文前必须按这个换算。

## 二、素材与角色卡（决定像不像）

### 角色卡的要求

| 项 | 要求 |
|---|---|
| **比例** | 和出片比例一致（竖屏出片就做竖卡） |
| **尺寸** | ≥ 1024×1024（竖版 896×1152 起） |
| **脸占比** | **30–40%**（缩放后脸部像素量决定像不像） |
| **内容** | 大头特写 + 正/侧/背三视图 |
| **质量** | 正面、平光、无遮挡、表情中性、**不要美颜磨皮** |

> 决定"像不像"的是**缩放后脸还剩多少像素**：`脸像素 ≈ 卡宽 × 脸占比`。
> 1024 的卡 + 35% 脸占比，`match` 就有约 230px 的脸。

### 素材与编号

素材面板按顺序编号 1、2、3…（**改面板顺序，剧本的 `图=` 要跟着改**）。
每个角色只用一张卡（含脸 + 三视图），不要拆成"纯脸"+ "纯身体"两张——模型会当成两个人。

### 【v3 新增】场景卡的禁令

**场景卡里不能有清晰人脸。** 遗照、海报、镜框照片、电视屏幕里的人，一律要求：

- 背对镜头，或
- 只拍相框侧面/背面，或
- 明确要求"blurred, out of focus, unreadable"

> 事故记录：《头七》第 18 段，墙上遗照变成了凶手的脸；第 6、20 段，遗照自己"站"了起来。
> 因为场景图里那张脸，被模型当成了要维持/替换的主体。

```
subject_definitions:
<Subject 1> is the exact frame in <Picture 1>: 场景 + 布光三要素 + 材质反应。
<Subject 2> is the man in <Picture 2>. Face: … Hair: … Clothing: … Voice: …

summary:
[reference generation] 一句话：这段发生什么。不要塞细节。

retention_analysis:

<Subject 2> (throughout): fully_preserved - exact face, hair, clothing.

detailed_description:

[Shot 1] At 00:00.000, 机位/景别/时长，一个动作 + 微表情 + 呼吸。
…

overall_soundscape:
物理声源…
No on-screen text, no captions, no subtitles.

non_diegetic_music:
N/A
```

**正文用英文写**（模型对英文最稳）。中文只出现在台词里。

## 四、高密度写法（v2 保留）

### 1. 主体卡要写四层

| 层 | 写什么 | 例 |
|---|---|---|
| **脸** | 五官、脸型、发际线、肤色、瑕疵 | `oval face, high cheekbones, faint mole under left eye` |
| **发型** | 长度、分缝、发色、质感 | `black hair in a loose low bun, strands loose at temples` |
| **服装** | 款式、颜色、**面料**、版型、配饰 | `off-white cotton shirt, slightly wrinkled, sleeves rolled to elbow` |
| **声音** | 年龄性别、音高、语速、口音、习惯 | `female, 25–30, mid-low pitch, fast pace, faint southern accent` |

> 颜色可以写，但以"和参考图一致"为前提：`hair colour exactly as in <Picture 2>` 比 `purple hair` 稳。

### 2. 场景段要写布光三要素

```
光位：window light from frame left, 45 degrees down
色温：warm late-afternoon light, slight amber cast
强度：soft, no harsh shadows on faces
```

再补一句**材质反应**：`matte concrete wall, thin reflection on the glass table`

### 3. 每个 shot 三件套

```
[Shot 2] At 00:02.000, 机位 · 景别 · 时长
         动作 + 微表情 + 呼吸 + 视线
```

- **机位**：`eye-level` / `low angle` / `over-shoulder` / `side profile`
- **景别**：`wide` / `medium` / `medium close-up` / `close-up`
- **时长**：每拍 1.5–2.5 秒

### 4. 密度目标

| 段长 | 正文目标字数 |
|---|---|
| 4 秒 | 600–800 |
| 6 秒 | 900–1200 |
| 8 秒 | **1200–1600** |
| 10 秒 | **1500–2000** |

**写不到下限 = 模型自由发挥 = 画面飘。** 但不要凑字：多写"光、材质、微表情、呼吸"，不要堆形容词。

## 五、镜头纪律（v3 核心，四条）

### 5.1 位置坐标块（STAGING 的固定写法）

**每段 STAGING 必须复用同一套坐标**，不要每段新写。写成四要素：

```
1. 谁在哪：the woman behind the counter at frame right
2. 朝向哪：facing the camera, three-quarter view
3. 手在做什么：both hands on the counter edge
4. 道具在哪：the rice ball at the center of the shelf, second row, label facing out
```

后面追加两句守卫句（**每段都写**）：

```
Nobody else is present.        ← 或 Nobody enters the frame.
Nobody walks toward or away from the camera.
```

> 事故记录：《头七》第 4 段香炉跑到女人身前；第 20 段遗照升空。
> 原因：位置只在第一段写过，后面靠模型"记得"。

### 5.2 动作动词：白名单 / 黑名单

**黑名单（禁止使用，实测会翻车）**

| 别写 | 会变成 |
|---|---|
| `walks out of frame` / `exits the room` | 倒着走、瞬移 |
| `walks away from the camera` / `turns and leaves` | 倒退出场 |
| `disappears down the stairs` | 反面朝天、身体拉长 |
| `both leave together` | 两人同向重叠、穿模 |

**白名单（安全）**

```
walks toward frame center / stops / turns his head / sits down / stands up /
raises his right hand / lowers the cloth / opens the door inward /
steps back one pace / puts it down on the table
```

只在必要时才写"离开"，且必须给方向和终点：

```
he turns and steps toward the glass door at frame left, and stops there
```

> 事故记录：《头七》第 14 段，沈亦舟倒退着退场，切镜后另一个人也倒着走。

### 5.3 说话人：正反打 + 嘴部明写

**规则一：两人同框不说话。** 说话镜头一律切成单人近景（正反打），
对方的脸放在另一个镜头里当反应。

**规则二：每句台词后面必须跟一句嘴部状态。**

```
[Shot 1] At 00:00.000, medium close-up on the man, 2s. He says quietly: "她不吃金枪鱼的。"
         His mouth moves; her mouth stays closed.
[Shot 2] At 00:02.000, medium close-up on the woman, 2s. She answers softly: "那明天我换一个。"
         Her mouth moves; his mouth stays closed.
```

**规则三：不要在"只剩一张脸"的镜头上放台词。**
特写遗照、特写后脑勺、特写手——同时有台词，观众会以为那张脸在说话。

> 事故记录：《头七》第 6 段遗照"开口说话"；第 23 段台词给错了人。

### 5.4 断链的两种类型（场景内切镜头 / 换场景）

每 ≤3 段必须断一次链，但**断链有两种，别混用**：

| 类型 | 图号 | 观众看到 | 用在什么时候 |
|---|---|---|---|
| **场景内切镜头**（最常见） | **不变**（还是 `新图:1`） | 同一个房间，换个角度 | 对话、反应、情绪推进 |
| **换场景** | 换成另一张（`新图:2`） | 人物到了别的地方 | 剧情真的换了地点 |

**判断方法**：问自己"人物有没有走到另一个地方"。没有 → 图号不变。

#### 切口选在哪

**安全切口（三选一）**

- 一句台词说完之后
- 一个人的反应镜头（不需要连续动作）
- 一个动作做完（门关上、杯子放下、转身完成）

**绝对要避开的切口**

- 动作进行到一半（手举到一半、正在转身、正在走）
  → 切到新镜头时动作会被"重置"，观众看到的是**跳帧**，不是切镜头

#### 断链段的第一帧怎么写

断链段的起幅图是场景图，容易看起来像一张静止照片。那一段的 `[Shot 1]` 必须写两件事：

```
[Shot 1] At 00:00.000, wide shot, 2s. Camera already pushing in slowly; the man is already
         standing at frame left, mid-breath.
```

- `Camera already pushing in / already in motion` ← 镜头已在运动
- `the man is already standing at frame left` ← 人已经在画面里

这两个短语能显著减少开头 0.3 秒的"静止照片"感。

#### 30 段的标准排布（可直接套）

| 组 | 段号 | 场景 | 接法 | 机位 |
|---|---|---|---|---|
| 1 | 1–3 | 场景1 | `新图:1` + 上一段 ×2 | 门口全景 |
| 2 | 4–6 | **场景1** | **`新图:1`** + 上一段 ×2 | 过肩/反打 |
| 3 | 7–9 | **场景1** | **`新图:1`** + 上一段 ×2 | 低角度 |
| 4 | 10–12 | 场景2 | `新图:2` + 上一段 ×2 | 中景 |
| 5 | 13–15 | **场景2** | **`新图:2`** + 上一段 ×2 | 特写 |
| 6 | 16–18 | 场景1 | `新图:1` + 上一段 ×2 | 全景（时间跳了） |
| 7 | 19–21 | **场景1** | **`新图:1`** + 上一段 ×2 | 双人中景 |
| 8 | 22–24 | 场景3 | `新图:3` + 上一段 ×2 | 纵深 |
| 9 | 25–27 | **场景3** | **`新图:3`** + 上一段 ×2 | 特写 |
| 10 | 28–30 | 场景4 | `新图:4` + 上一段 ×2 | 全景收尾 |

**规律：`新图:X` 每 3 段出现一次，但 X 只在真正换景时才变。同一场戏里 X 保持不变。**

### 5.5 关键信息：必须有画面证据

**凡是靠台词才能明白的剧情，都要配一个画面证据。**

| 纯台词（不可靠） | 配画面证据 |
|---|---|
| "这里死过人" | 椅背上的枯花 + 泡烂的卡片 |
| "刹车被人动了" | 刹车踏板的插入镜头 |
| "我录了七天" | 手机/录音笔的红色指示灯亮起 |
| "他是我丈夫" | 两人的结婚照（无脸，只有手和戒指） |

**结尾台词必须能被前面的画面支撑**，否则观众一定懵。

> 事故记录：《头七》结尾"先把你的葬礼办完 / 这次我等你"，
> 前面没有任何"葬礼办完=他能活回来"的画面，观众完全看不懂。

## 六、写作规则（v1 + v2 + v3）

1. **一拍一件事**：4 秒 2 拍 / 6 秒 3 拍 / 8 秒 4 拍 / 10 秒 5 拍 / 12 秒 6 拍。
2. **构图先写**：第一句必须写死机位和景别，不要用 `cinematic shot` 这种空话开头。
3. **脸必须在框内**：每段结尾加 `All faces stay fully inside the frame`。
4. **不越轴**：全片固定方位，每段在 STAGING 复述。
5. **身份要写足**：只写 `is <Picture 2>` 会让两个同性角色越长越像。
6. **多人同框 ≤ 3 人**，第三人必须被动。
7. **禁写极端特写**：退到中近景，画面里至少留一张脸。
8. **台词内联**：`<Subject 2> says quietly: "…"`；念稿异常时用 `<d>[Chinese] …</d>`。
9. **状态要复述**：每段开头说明"他正躺着/她外套已脱"——段与段之间没有记忆。
10. **别让角色自己站起来**：除非剧情要求，写死姿势。
11. **台词短**：一句 6–12 字，超过 15 字容易念糊。
12. **结尾收小**：最后一拍做收尾小动作。
13. **说话人编号**：多人同框写 `(S1)`。
14. **道具做主语 + 被动语态**：`the gun is forced back, still held in her hand`。
15. **音效只写物理声源**：`fabric rustle, wet contact, quiet room tone`。
16. **每段必须有"人已经在画面里"的表述**，避免开头空镜。
17. **情绪写表现不写感受**：`her jaw tightens, one quick breath`，不写 `she is nervous`。
18. **一句只给一件事**：不要在一句里要求两个动作。
19. **【v3】起幅图 = 本段第一画面**：见 7.1。
20. **【v3】全片禁止"走出去/背向走"**：见 5.2。
21. **【v3】每段 STAGING 逐字复用坐标块**：见 5.1。
22. **【v3】说话镜头必须正反打 + 嘴部明写**：见 5.3。
23. **【v3】关键剧情必须有画面证据**：见 5.4。

### 景别词表

`extreme close-up` 大特写 / `close-up` 特写 / `medium close-up` 近景 / `medium shot` 中景 /
`medium wide shot` 中远景 / `wide shot` 全景

## 七、v3 新增：起幅与参考位

### 7.1 图= 的第一位 = 本段真正的第一画面

不是"身份锚点"。观众第一眼看到的应该是什么，第一位就放什么：

| 这段第一帧是 | 第一位放 | 合理吗 |
|---|---|---|
| 场景全景 | 场景图 | ✅ |
| 道具特写 | 道具图 | ✅ |
| 人物中景 | **带环境的人物图** | ✅ |
| 人物中景 | **纯背景人像卡** | ❌ 禁止 |

### 7.2 纯背景人像卡绝对不能当起幅

那种卡的特征太强（深色背景、正面大脸、平光），模型一开局就把它"复述"出来，
观众立刻看出这是素材照。

> 事故记录：《头七》第 28 段第 0 帧与角色卡像素差异仅 13.7 —— 等于把素材照播出来了。
> 《最后一班》改成"场景在前、人像卡在后"，10 段里没有一段出现素材照开头。

### 7.3 人像卡只放参考位第 2、3 位

它负责"长相"，不负责"第一帧"。

```
图=1,4      ← 场景 + 男人卡（正确）
图=4,3      ← 男人卡 + 女人卡（错误：没有场景锚，第一帧必然是人像）
```

## 八、交付前自检清单

### A. 格式（引擎会直接拒绝的）

- [ ] 每块头行四字段齐全，**用 `=` 不用 `:`**
- [ ] `角色=` 里逗号后**没有空格**
- [ ] `续接` 只有 `新图:N` / `新图:名字` / `上一段`
- [ ] `图=` 序号与素材顺序一致
- [ ] **每条链 ≤ 3 段**，断链处换了机位或景别
- [ ] **断链时没有乱换图号**：同场景断链仍用同一张场景图（`新图:1` 还是 `新图:1`），只有真换地点才换号
- [ ] 六段齐全
- [ ] 正文零中文（中文只在台词里）
- [ ] `overall_soundscape` 末尾有 `No on-screen text, no captions, no subtitles.`

### B. 镜头纪律（v3 必查）

- [ ] **起幅**：`图=` 第一位是不是这段第一画面？人像卡有没有排到两位以后？
- [ ] **动作**：全篇有没有 `walks out of frame` / `away from camera` / `leaves`？有就改
- [ ] **手**：每个动作镜头有没有写"手在做什么"？
- [ ] **说话**：每个说话镜头有没有写"谁嘴动、谁嘴闭"？有没有两人同框说话？
- [ ] **位置**：STAGING 有没有逐字复用同一套坐标？道具位置有没有复述？
- [ ] **信息**：关键剧情有没有画面证据？还是全靠台词说？
- [ ] **字数**：达到该段长下限（8 秒 ≥1200 字，10 秒 ≥1500 字）

### C. 六句口诀（最后过一遍）

```
开头：第一位是不是这段第一画面？人像卡在不在后面？
动作：有没有"走出去/背身走"？手在干什么写了吗？
说话：谁张嘴写了吗？镜头里是不是只有一张脸？
位置：每个人在哪、朝哪，写了吗？道具位置复述了吗？
信息：关键剧情画面能证明吗？还是全靠嘴说？
字数：到下限了吗？
```

## 十、常见失败与修法

| 现象 | 成因 | 修法 |
|---|---|---|
| 角色念旁白似的乱语 | 正文里有中文人名 | 正文零中文，角色用 `<Subject n>` |
| 画面出现字幕 | 提示词带引号文字 | 没台词就不写引号，并加 `No captions / no subtitles` |
| 开头 0.3 秒空镜 | 第一句是空话 | 第一句写机位 + 景别 + 主体位置，并写"already in frame" |
| 人物越拍越像 | 只写 `is <Picture n>` | 补脸型/发型/服装面料 |
| 脸不像 | 角色卡脸占比太小 | 重做卡：脸占 30–40%，尺寸 ≥1024 |
| 画面"廉价" | 没写材质和布光 | 补：光位 / 色温 / 材质反光 |
| 语言乱、念稿 | 正文太短，中文太多 | 补到字数下限，正文全英文 |
| 说话的人不动嘴 | 没标 `(Sx)` | 写 `<Subject 2> (S1) says: "…"` |
| 接缝顿一下 | 上段在大幅动作中结束 | 最后一拍收小 |
| 动作粘连/多手多脚 | 一段里两人同时主动 | 拆段，或让一人被动 |
| 眼神空洞 | 没写视线 | 每个 shot 写 `looking at frame left / at his face` |
| **开头播了素材照** | 人像卡当了起幅 | 场景/道具放 `图=` 第一位，人像卡退到 2、3 位 |
| **人物倒着走** | 写了"走出去/背向走" | 换白名单动词，给方向和终点 |
| **凭空多一个人** | 位置描述只写了一次 | 每段 STAGING 复述坐标 + `Nobody else is present.` |
| **道具自己跑位** | 道具位置没复述 | 每段重复"在桌面正中/右扶手" |
| **台词给错人** | 两人同框说话 | 改正反打，加 `His mouth moves; her mouth stays closed.` |
| **照片里的人说话** | 说话镜头里只有一张脸 | 说话镜头必须是中近景，且拍活人 |
| **场景里的照片换脸** | 场景卡里有清晰人脸 | 重做场景卡：照片虚化/背对/只拍框 |
| **结尾看不懂** | 纯逻辑台词，无画面支撑 | 给画面证据，或改更直白的台词 |

## 十二、交接与执行（给别的 AI，或自己跑之前）

模板写好了不等于能出片。这一章是"交付环节"的规则，全部是踩过的坑。

### 12.1 先定三件事（不定就别开写）

| 项 | 说明 |
|---|---|
| **素材清单** | 第几张是场景、第几张是谁。**编号必须和素材面板顺序一致** |
| **比例与段数** | 例如 16:9 / 20 段 × 8 秒 = 160 秒 |
| **接法** | 硬接（每段锚上段尾帧）还是关 |

> **素材顺序排错 = `图=` 全错 = 整篇重写。** 这是最常见的返工点。

### 12.2 给其他 AI 的指令（可直接粘）

```

### 12.3 拿到稿子先扫七条

| # | 查什么 | 怎么查 |
|---|---|---|
| 1 | `图=` 第一位是不是该段第一画面 | 人像卡当起幅 = 开头播素材照 |

### 12.4 参数与时间预期

## 十三、电影级镜头语汇（v4 新增）

> 这一章解决的是"镜头为什么这样选"，而不只是"怎么写英文词"。
> 核心顺序：**先想清楚要观众看到什么，再选景别；再决定摄像机怎么动。**

### 13.1 先定意图，再选景别

| 你想让观众… | 用 | 英文写法 |
|---|---|---|
| 知道"她在哪" | **远景** | `extreme long shot` / `wide shot` |
| 看清"她怎么动" | **全景** | `full shot`（整个人 + 周围空间） |
| 看懂"她和谁互动" | **中景** | `medium shot`（腰以上，兼顾表情和身体） |
| 看出"她情绪变了" | **近景** | `medium close-up`（胸以上，表情为主） |
| 发现"她眼里的线索" | **特写** | `close-up` / `extreme close-up` |
| 强调一个物件/细节 | **插入镜头** | `insert shot`（道具特写，不给脸） |

> 景别决定观众**看多大范围**；运镜决定观众**如何发现信息**。

### 13.2 景别与用途（含误用）

| 景别 | 画面 | 典型用途 | 常见误用 |
|---|---|---|---|
| 远景 | 人物很小，环境是主体 | 交代地点、氛围、孤立感 | 用来演戏 → 看不清表情 |
| 全景 | 完整身体 + 空间 | 站位、走动、完整动作 | 对话戏用它 → 表情丢失 |
| 中景 | 腰以上 | 对白、互动、关系变化 | 情绪高潮用它 → 不够近 |
| 近景 | 胸以上 | 情绪转折、迟疑、心动 | 连续用 → 观众疲劳 |
| 特写 | 脸/眼睛占满 | 关键情绪、发现线索 | 全片滥用 → 廉价 |
| 插入镜头 | 只有手/道具 | 证据、伏笔、动作结果 | 说话时用它 → 以为道具在说话 |

### 13.3 运镜（写**方向 + 幅度 + 速度**三件事）

| 运镜 | 英文写法 | 观众得到什么 | 翻车点 |
|---|---|---|---|
| **推** | `slow push in, from medium to close-up by the end` | 注意力集中、压迫感 | 推太快 → 晕 |
| **拉** | `slow pull out, revealing the empty street behind her` | 揭示环境与关系、孤独 | 拉出后出现多余人物 |
| **移**（横移） | `lateral tracking left, revealing the man behind the tree` | 改变观察位置、揭示遮挡 | 移动中人物变形 |
| **摇** | `pan right to follow her gaze` / `tilt down to the hand` | 引导视线 | 摇太快 → 模糊 |
| **升降** | `boom up, from her face to the whole courtyard` | 从人物过渡到空间 | 升太高 → 人变蚂蚁 |
| **跟** | `follow her as she walks, camera stays behind her shoulder` | 沉浸、跟随感 | 背向镜头 → 容易倒着走（见 5.2） |
| **环绕** | `slow orbit around the two of them, 90 degrees` | 关系张力、对峙 | 转太快 → 脸崩 |
| **手持** | `handheld, slight shake` | 不安、纪录感 | 抖动过大 → 像故障 |

**写法模板**：

```
[Shot 2] At 00:02.000, medium close-up, slow push in over 2s.
         The camera starts at her shoulder and ends 30cm from her face;
         her eyes fill the right third of the frame.
```

### 13.4 每个 shot 的五件套（升级第四章的"三件套"）

```
[Shot N] At MM:SS.mmm, 机位 · 景别 · 运镜（方向/幅度/速度） · 时长
         焦段/景深（可选，但强烈建议） · 光位（可选）
         动作 + 微表情 + 呼吸 + 视线
```

| 件 | 例 |
|---|---|
| 机位 | `eye-level` / `low angle` / `over-shoulder` / `side profile` |
| 景别 | `wide` / `full` / `medium` / `medium close-up` / `close-up` |
| 运镜 | `slow push in` / `static` / `lateral tracking left` |
| 焦段 | `35mm, deep focus`（环境叙事）/ `85mm, shallow depth of field`（人物特写） |
| 光位 | `window light from frame left, 45 degrees down` / `backlit from the door` |

### 13.5 段落级镜头配方（每段 8 秒取 1–2 个，别塞满）

**对话戏**（两人对峙）

```
① 中景 · 固定（建立位置）
② 近景 · 固定（A 说话）
③ 近景 · 固定（B 反应）
④ 过肩 · 缓慢推（情绪升级）
```

**情绪戏**（一个人崩溃/释怀）

```
① 近景 · 固定（初始表情）
② 特写 · 极慢推（眼睛）
③ 中景 · 缓慢拉（孤独感）
④ 全景 · 固定（人物与空间）
```

**动作戏**（抢东西、摔门、打斗）

```
① 全景 · 固定（动作完整可读）
② 中景 · 跟（跟着动）
③ 插入镜头 · 固定（手 / 道具）
④ 近景 · 固定（结果表情）
```

**转场**（换地点/时间跳跃）

```
① 占位空镜 · 固定（门/窗/街）
② 远景 · 缓慢拉（新地点）
```

**收尾**（片尾）

```
① 远景 · 极慢拉 / 升（把人物放进世界）
② 静止 2 秒（不要切）
```

### 13.6 硬规则（违反必翻车）

1. **同一场戏里，连续两段不许用完全相同的 机位+景别**（否则像卡帧）
2. **一段（8 秒）里运镜不超过 1 个**，写清方向与幅度
3. **特写占比不超过全片 20%**，否则观众疲劳、画面廉价
4. **说话镜头不用特写/插入镜头**（见 5.3：会出现"物件说话"）
5. **动作戏优先全景**，情绪戏优先近景——反了就是"看不清动作 + 表情过重"
6. **运镜必须能被一句话说清**：说不清就是设计过度

### 13.7 英文速查（直接抄）

```
景别：wide shot / full shot / medium shot / medium close-up / close-up / insert shot
机位：eye-level / low angle / high angle / over-shoulder / side profile / POV
运镜：static / slow push in / slow pull out / lateral tracking / pan left|right /
      tilt up|down / boom up|down / follow / slow orbit / handheld
焦段：24mm wide / 35mm / 50mm / 85mm portrait / shallow depth of field / deep focus
光位：key light from frame left / rim light from behind / backlit by the window /
      practical lamp on the table / soft overcast light
```
