# Vanco 分镜编排引擎 v1

> 给 ComfyUI + MiniMax-H3 用的**长片编排**节点包：贴一份分镜脚本、传一组素材图，一次点击逐段生成、自动衔接、自动拼成片；哪一段不满意可以单独重做，不必整条重跑。

---

## 和常见"导演台"的区别

多数多段工作流只能二选一：要么全局强制接上一段尾帧，要么每段完全独立、靠手工摆节点。

本包把**每一段都变成可独立编排的单元**，同时保留"一键跑全片"：

| 能力 | 说明 |
|---|---|
| **逐段选图** | 头行 `图=2,3,5`，本段只喂这几张素材（不写则喂全部，上限 8 张） |
| **接法自由** | 每段自己决定：`续接=上一段`（参考上段尾帧）/ `续接=新图:2`（硬切换场景）/ `硬接模式`（FL2VA 首帧锚定） |
| **单段可修** | `只跑第N段` + `下游处理=级联重跑`；或 `精确重跑=首尾帧` 把结尾钉到下一段首帧 |
| **超分可选** | 成片后可接 ReCaVSR 或 RelayVSR（两套方案，不是叠加两次） |

其它内建能力：逐段色彩归一（防越跑越脏）、链长警告（连续接力 >3 段提示）、人物检测与空镜裁剪、分段耗时日志、段级进度条、运行报告与界面警告浮层、`latest.mp4` 最新版指针。

## 安装

1. 把本仓库整个目录放到：
   ```
   ComfyUI/custom_nodes/ComfyUI-Vanco-Suite/
   ```
2. 依赖（一般 ComfyUI 环境已具备）：
   ```bash
   pip install -r requirements.txt
   ```
3. 模型放到 ComfyUI 的 models 目录（**不随仓库分发**）：
   - MiniMax-H3 主干（FL2VA / REF2VA）、文本编码器、视频 VAE、音频 VAE
   - 可选：`models/yolo/yolov8n.onnx`（人物检测用，约 12 MB；不装则检测功能自动跳过）
4. **外部节点依赖**（本包不含，需自行安装）：
   - AV 解码节点 `MiniMaxH3AVDecodeT8`（来自 `minimax-h3-audio-T8`）
   - 视频超分：`ComfyUI-ReCaVSR`（用 ReCaVSR 时）/ RelayVSR 对应包（用 Relay 时）
5. 重启 ComfyUI，节点出现在 `Vanco/*` 分类下。

## 快速开始

1. 导入 `workflows/Vanco-H3-分镜编排引擎-v1.json`
2. 左侧 `📄 提示词模板` 是写剧本的规范，交给任意大模型即可产出可用分镜
3. 素材面板上传图片（顺序即编号 1、2、3…），接到引擎的 `素材` 输入
4. 把 `Vanco H3 模型加载器` 的 `h3_bundle` 接到引擎的 `h3_bundle` 输入（首尾帧/硬接模式需要）
5. 填剧本 → 运行

剧本头行格式：

```
[1] 续接=新图:1 角色=男主,女主 图=1,2,3 秒=8
（六段式正文）
```

## 输出

```
output/视频合集/Vanco/多段导演台/<剧本名>/
├── 分段/   segNN_vN.mp4 + .json（参数与指纹）+ _last.png（无损尾帧）
└── 成片/   合并-<时间戳>.mp4 / latest.mp4 / 当前版本.txt / _运行报告.txt
```

## 已知限制

- `续接=上一段` 是**参考引导**，不是像素级硬接；要锁构图请用 `硬接模式`（需 FL2VA 主干）
- 连续接力超过 3 段画质会漂移（模型特性，同类工作流都一样）
- VAE 显存不足时会分块解码，可能出现局部模糊
- 多段为串行生成，不支持并行
- `图=` 序号对应素材面板顺序，改动面板顺序需同步改剧本
